해자가 나오는 곳

1. 4.0%p 변동폭의 안정성

최근 8개 분기 영업이익률은 23.9~27.9%(폭 4.0%p), 8개 분기 연속 흑자다. 2026년 2분기 매출 180억원·영업이익 50억원·이익률 27.6%, 상반기 누적 340억원·94억원, TTM 27.7%다. 연간으로도 2021년 27.4%·2022년 31.0%·2023년 24.3%·2024년 22.7%·2025년 27.1%로 5년 내내 22%를 넘는다. 최신 분기 이익률은 같은 정보서비스 업종 18개사 중 5위(중앙값 5.94%)다. 분기 매출 160억~181억원으로 외형은 작으나, 분기마다 40억원대 후반이 남는 규칙성이 있다. 연결·별도가 섞인 해가 있어 앞뒤 비교에 주의가 필요하다는 묶음 주석은 감안했다.

2. 반복 과금형 API 플랫폼

수익모델은 초기 도입비(라이선스·기술지원)와 월 수수료(정액·종량)로, 반복 수수료 비중이 높은 구조라고 공시한다. 국내 500여 개·해외 40여 개국 2,000여 기관과 연계해 약 5만 종 데이터를 수집하고 300여 종 API 상품을 국내 최대 정보 API 플랫폼으로 제공한다. 데이터 서비스(반기 165억원)와 페이먼트 서비스(175억원)가 균형을 이루고, 반기 매출 340억원·연간 700억원 안팎이 꾸준히 나온다. 오픈뱅킹·마이데이터 제도 도입과 함께 수요가 는다는 서술대로, 제도·디지털 전환이 깔아준 레일 위에서 과금한다.

3. 연계망이라는 자산

국내 90개 이상 금융기관 실시간 연계 전자금융 네트워크, 전용망·스크래핑·오픈 API 수집 기술, 300여 건 지식재산권, 대형 금융기관 수준 보안 클라우드, 2023년 7월 데이터전문기관 라이선스(결합·분석까지 확장)가 공시된다. 금융·공공·의료·유통·통신 개인정보·기업정보·글로벌 API, 간편결제·전자금융·크로스보더 결제까지 상품군이 넓다. 고객으로 주택도시보증·우리·농협·현대해상·DB손보·KB·삼성증권·네이버파이낸셜 등이 열거된다. 20년간 수집·연결 기술·망 고도화에 집중했다는 서술과, 반기 광고선전비 3.7억원(매출의 약 1%)·지급수수료 성격 비용이 작은 구조가 맞아떨어진다. 파는 것이 아니라 연결해주는 것이라 광고가 필요 없다.

4. 제도 수혜의 지속성

마이데이터·오픈뱅킹·비대면 금융 확산이 거래량·매출로 이어진다고 공시하며, 마이데이터 상품 확대·비금융(의료·유통·물류) 확장·글로벌 진출을 계획으로 적시한다. 단순 ROE 11.7%(자본 1,887억원·자산 3,633억원)는 장치 없이 버는 플랫폼치고 준수하다.

비판적으로 봐야 할 것

5. 고객 이탈 비용

기업 고객은 쿠콘 API를 자산관리·대출심사·자금관리·경비·결제 같은 내부 업무 흐름에 박아 넣는다. 개인정보·기업정보·글로벌 API, 간편결제·전자금융·크로스보더까지 한 계약으로 묶여 있으면, 갈아타는 쪽이 시스템·정합성·보안 심사를 다시 치러야 한다. 반기 데이터 165억원·페이먼트 175억원이라는 균형도 한쪽이 흔들려도 다른 쪽이 버틴다는 뜻이다. 500개·2,000개 기관 연계망은 하루아침에 복제되지 않으며, 300여 종 API 상품군은 고객이 쓸수록 늘어나는 구조다. 그래서 정액·종량 월 수수료가 끊기지 않는다.

비판적으로 볼 것

1. 업종 1위가 아니다

최신 이익률 27.6%·TTM 27.7%는 이크레더블(62점·53.3%), 에프앤가이드(59점·52.7%), 서울평가정보(54점·42.7%), 리파인(42점·34.4%)보다 낮다. 안정성(4.0%p)은 비교군 최고 수준이나, 상한이 27.9%에 갇혀 있다. 분기 매출 180억원·반기 340억원 규모라 대형 고객 1~2곳 이탈·단가 재협상에도 흔들린다. 주요 고객별 매출 비중은 묶음과 원문 검색에서 확인되지 않아 공시에서 확인하지 못함으로 둔다. 연결 범위 변경 해(2024년 별도 전환 등)의 앞뒤 비교도 제한적이다.

2. 데이터 수집 의존과 규제

수집원이 외부 기관(500개·2,000개 기관)이라, 기관의 제공 중단·유료화·직접 API화 시 원가·공급이 흔들린다. 개인정보보호법·신용정보법 준수, 데이터전문기관 라이선스 유지가 전제이며, 제도(마이데이터·오픈뱅킹) 속도·범위가 바뀌면 성장 기울기가 달라진다. 글로벌 40개국·2,000개 기관 연계의 실제 매출 기여도, 페이먼트 대 데이터의 부문별 이익은 묶음에 없어 공시에서 확인하지 못함으로 둔다.

3. 순이익 변동

영업은 안정적이나 순이익은 2025년 3분기 6억원·4분기 8억원 대 2026년 1분기 74억원·2분기 132억원으로 출렁인다. 영업 외·지분·평가 항목의 영향으로 보이며, 내역은 발췌에 없어 공시에서 확인하지 못함으로 둔다. ROE 11.7%도 순이익 변동에 따라 움직인다.

총평

같은 정보서비스 업종에서 상위권이나 1위는 아니라고 판단한다. 이익률 27.6%·TTM 27.7%·4.0%p 안정성은 이크레더블(62점·53.3%), 에프앤가이드(59점·52.7%), 서울평가정보(54점·42.7%)보다 낮고, 리파인(42점·34.4%)·아이지넷(43점·12.0%)보다는 높다. 그래서 에프앤가이드·서울평가보다 위가 아니라 아래, 리파인보다는 위인 60점대 초반이 합당하다. 이크레더블(62점·연간 31%·TTM 30.6%)보다 2점 아래로 매긴 근거는, 쿠콘의 안정성(4.0%p 대 46.6%p)이 위이나 마진 상한·ROE(11.7% 대 30.6%)가 아래이기 때문이다. 한쪽은 꾸준하고 한쪽은 높다. 업종 중앙값 39·중앙 이익률 5.94%보다는 확연히 위이며, 게임업 평균 30·위워크 10과는 차원이 다르다. 진입장벽 74, 전환비용 62, 브랜드·IP 62, 네트워크효과 55, 가격결정력 62, 마진추세 68을 종합해 최종 60점으로 판단한다.

사업의 개요▾

쿠콘은 데이터 기반 디지털 전환 수요 확대에 대응하여, 외부 기관의 데이터를 수집, 정제, 표준화하여 API 형태로 제공하는 데이터 중개 플랫폼 기업입니다. 당사는 전용망, 스마트 스크래핑, 오픈 API 등의 기술을 활용하여, 데이터를 수집ㆍ연결하고, 이를 기업 고객에게 비즈니스 API 형태로 제공합니다.

2026년 2분기 기준, 국내 약 500여 개, 해외 40여 개국 2,000여 기관과 연계하여 약 5만 종의 데이터를 수집하고 있으며, 이를 기반으로 300여 종의 API 상품을 개발하여, 국내 최대 정보 API 플랫폿 「쿠콘닷넷」을 통해 금융기관, 빅테크ㆍ핀테크 기업, 공공기관, 일반 기업 등에 서비스를 제공하고 있습니다. 또한 쿠콘 API는 디지털 개인자산관리(PFM) 서비스, 금융상품 추천, 자동화된 비대면 금융업무 처리 등 다양한 디지털 서비스 구현에 활용되며, 오픈뱅킹, 마이데이터 등 제도 도입과 함께 시장 수요도 지속 증가하고 있습니다.

당사의 API 상품은 데이터 서비스와 페이먼트 서비스로 구성됩니다.

(1) 데이터 서비스 데이터 서비스는 금융, 공공, 의료, 유통, 통신 등 다양한 산업 분야에서 활용되는 개인정보, 기업정보, 글로벌 정보 등을 API 형태로 제공합니다.

- 개인정보 API: 자산, 금융, 실물정보 등 개인 관련 정보를 수집하여 B2C 솔루션 사업자에게 제공합니다.

- 기업정보 API: CMS/ERP 등 기업 내부 시스템 연동을 위한 기업정보를 제공하여 업무 자동화를 지원합니다.
