해자 관점 긍정 요소

모아 놓은 연결이 곧 상품이다. 회사가 자기를 "외부 기관의 데이터를 수집, 정제, 표준화하여 API 형태로 제공하는 데이터 중개 플랫폼 기업" 으로 규정하고 그 규모를 숫자로 낸다 — "국내 약 500여 개, 해외 40여 개국 2,000여 기관과 연계하여 약 5만 종의 데이터를 수집하고 있으며, 이를 기반으로 300여 종의 API 상품을 개발" 해 국내 최대 정보 API 플랫폼 「쿠콘닷넷」 으로 제공한다.

그 연결 자체가 시간으로만 쌓인다. 기관 하나를 붙이려면 전용망·스크래핑·오픈 API 로 연결하고 데이터를 정제·표준화해야 하는데, 2,500여 곳을 이미 붙여 놓은 것을 새로 하려면 같은 시간이 든다(진입장벽 55). 그리고 연결 기관이 늘수록 만들 수 있는 API 상품이 늘고, 상품이 많을수록 고객이 한 곳에서 해결한다(네트워크 60 — 이 프레임에서 네트워크효과가 실제로 작동하는 드문 경우다).

고객 시스템에 박힌다. API 는 고객의 서비스 코드에 연동돼 돌아가므로 바꾸려면 개발과 검증을 다시 해야 하고, 회사가 "디지털 개인자산관리(PFM) 서비스, 금융상품 추천, 자동화된 비대면 금융업무 처리 등 다양한 디지털 서비스 구현에 활용" 된다고 쓴다(전환비용 60).

상품이 두 갈래다 — 데이터 서비스(개인정보 API·기업정보 API·글로벌 API)와 페이먼트 서비스(간편결제 API·전자금융 API). 후자는 "국내 90개 이상의 금융기관과 실시간으로 연계된 전자금융 네트워크" 를 기반으로 간편결제·금융 VAN 을 제공한다 — 데이터 조회와 자금 이동이라는 다른 성격이다.

제도가 수요를 만든다 — 회사가 "오픈뱅킹, 마이데이터 등 제도 도입과 함께 시장 수요도 지속 증가" 한다고 쓴다.

마진이 오르고 있다 — 연간 22.71% → 27.15% 이고 이번 27.92%다.

비판적으로 봐야 할 것

재무 시계열이 셋뿐이다(연간 둘 + 분기 하나, 함정 11-3-1). 분기 흐름을 못 그려 계절성도 추세도 확인할 수 없고, 연결 없이 별도만 있어 종속 구조도 모른다.

매출이 730.4 → 694.6억으로 −4.9% 다. 마진은 올랐는데 매출이 줄었고 회사가 이유를 밝히지 않는다 — 연결 기관과 API 상품은 늘었다는데 매출이 줄었다면 건당 단가가 내려간 것일 수 있는데 그 자료가 없다.

고객을 하나도 밝히지 않는다. 금융기관·빅테크·핀테크·공공기관이 고객이라 쓰는데 집중도·실명·계약 형태가 없다 — 마이데이터 사업자가 소수라 몇 곳에 몰려 있을 수 있다.

API 단가·호출 건수·상품별 매출이 없다. 데이터 서비스와 페이먼트 서비스의 비중도, 국내와 해외의 비중도 없어 5만 종·300여 종·2,000여 기관이 매출에서 어떻게 나뉘는지 모른다.

데이터를 남에게서 받는다. 회사가 수집하는 것이 외부 기관의 데이터이므로 그 기관들이 정책을 바꾸거나 직접 API 를 열면 자리가 좁아지는데 — 오픈뱅킹·마이데이터가 수요를 만든다고 쓰면서 그 제도가 중개 필요를 줄이는 방향일 수도 있다는 위험은 서술하지 않는다.

스크래핑 기술의 법적 위치도 언급이 없고, 페이먼트의 총액/순액 인식과 수수료율도 없다.

총평

그 위로 못 올린 것은 매출이 −4.9% 라는 것과 재무 시계열이 셋뿐이라는 것이다. 기관과 상품은 늘었는데 매출이 줄었다면 단가가 내려간 것일 수 있고, API 단가·호출 건수를 하나도 내지 않아 확인할 수 없다.
