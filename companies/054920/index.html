중계 서비스가 네트워크 자리다 — withAuth 는 여러 전자서명인증사업자를 한 창구로 묶어 서비스 제공자가 한 번만 연동하면 여러 인증 수단을 쓸 수 있게 한다.

양자내성암호를 이미 제품에 얹었다 — 2024년 양자컴퓨팅 공격에 대비한 PQC 기술을 탑재한 '한컴 엑스커넥트 v4.0'과 '한컴 엑스디비 v5.0' 을 출시했다. 암호는 규격이 바뀌면 시스템 전체를 갈아야 하므로 먼저 붙는 쪽이 유리하다.

공공·금융 진입 자격을 땄다 — 한컴오스(Hancom Auth)가 2025년 7월 GS인증 1등급을 받아 공공 조달 요건을 갖췄다.

한 번 깔면 바꾸기 어렵다 — 암호화 솔루션은 데이터베이스와 통신 구간에 붙어 있고, 인증은 로그인 흐름 전체에 들어가 있어 교체하려면 시스템을 다시 검증해야 한다 (전환비용 45).

별도 마진이 두 자리에 가깝다 — 본체(한컴위드) 연간이 8.28%(2024) → 9.78%(2025) 이고 이번 분기도 7.79%다. 소프트웨어 사업 자체는 남는다.

자회사가 금 유통을 디지털로 옮기고 있다 — 한컴금거래소가 디지털 금 거래 플랫폼과 P2P 비대면 채널을 운영한다.

비판적으로 봐야 할 것

보안이 연결 매출의 1.37%다.

품목별 매출을 다 더하면 PKI 8.1억 + 간편인증 2.4억 + 생체인증 0 + 데이터보안 4.4억 + 모바일보안 2.1억 + 통합인증 2.2억 + 기타 3.3억 + 상품 0.4억 = 22.8억이고, 연결 매출 1,659.7억의 1.37% 다.

나머지 98.6%가 한컴금거래소의 금 도매다. 아이티센글로벌(38)이 매출의 92.65%가 금 도소매였던 것과 같은 구조이고, 비중은 더 극단적이다(함정 4-2).

매출이 한 해에 1.7배가 됐다 — 연간 4,481.8 → 7,712.2억이고 1분기끼리도 786.8 → 1,597.4 → 1,659.7억이다. 금값이 오르는 국면인데 거래량·재고자산 변동·매입 단가를 하나도 공시하지 않아 그 증가가 물량인지 값인지 가릴 수 없다(관찰 15).

별도와 연결이 자릿수가 다르다 — 별도 9.78% vs 연결 0.79% 다. 별도 매출이 179.8억으로 연결의 2.3% 이고, 이번 분기도 별도 7.79% / 연결 0.04% 다. 금 도매가 마진을 0%대로 끌어내린다(관찰 14).

이번 분기가 0.04%다 — 1,659.7억을 팔아 0.6억이다.

생체인증 매출이 0이다. 한컴오스가 GS인증 1등급을 받았다는 것이 근거인데 그 제품의 매출이 0 이고, PQC 제품의 매출도 따로 밝히지 않는다.

부문별 손익이 없다. SW 와 귀금속의 영업이익을 나누지 않는다.

금은 값을 국제 시세가 정한다. 회사가 "단순 유통을 넘어" 라 쓰지만 디지털 플랫폼의 매출·거래액·수수료율을 밝히지 않는다.

보안 시장의 경쟁 구도·점유율이 없다. 국내 인증·암호 시장은 사업자가 많은데 자기 자리를 밝히지 않는다.

한컴 계열 매출 비중이 없다.

PKI·간편인증·생체인증·데이터 암호화·모바일 보안·통합인증으로 층을 다 갖춘 것, withAuth 가 여러 전자서명인증사업자를 한 창구로 묶는 중계 서비스인 것, 2024년 양자내성암호(PQC)를 엑스커넥트·엑스디비에 탑재한 것, 한컴오스의 GS인증 1등급, 암호화가 시스템에 박혀 교체가 어려운 것, 별도 마진이 9.78%로 소프트웨어 사업 자체는 남는 것이 근거다.

아이티센글로벌(38)과 같은 점수다. 그 회사도 IT 서비스 위에 금 유통이 얹혀 IT가 7.33%뿐이었고 관찰 15의 확인 항목을 하나도 통과하지 못했다. 이 회사는 보안이 1.37%로 더 낮은데 대신 별도 마진이 9.78%로 본체가 확실히 남는다.

모다이노칩(40)·드림시큐리티(40)보다 두 점 아래인 것은 비중 차이다. 그 회사들은 상호가 가리키는 본업이 각각 14.4%·6.25% 였다.

38 위로 못 올린 것은 연결 0.79%와 금값 국면이다. 매출이 한 해에 1.7배가 됐는데 거래량도 재고 변동도 밝히지 않아 그 증가가 사업인지 시세인지 가릴 수 없고, 근거로 든 생체인증은 매출이 0이다.
