결론: 데이터 자산과 전문 언어 역량은 강점이지만, 네트워크 효과보다 실행력에 의존한다

플리토의 사업은 AI 언어 모델 연구개발용 데이터 판매, 플랫폼 기반 번역 서비스, AI 실시간 통번역 솔루션으로 나뉜다. 이 구조의 핵심은 일반적인 번역 앱의 사용자 수가 아니라, 전문 분야·희소 언어·텍스트·음성·이미지 데이터를 정제해 고객의 AI 개발에 공급할 수 있는 능력이다. 따라서 해자의 중심은 네트워크 효과보다는 데이터 품질, 구축 파이프라인, 특정 언어 조합의 희소성, 고객 시스템에 연결된 솔루션 경험에 가깝다.

1. 매출 구성은 데이터 판매가 중심이지만, 계약형·프로젝트형 성격이 섞여 있다

회사는 데이터 판매와 솔루션을 고객과 직접 계약하고, 플랫폼 서비스는 직접 판매 또는 플랫폼 내 결제로 제공한다고 공시한다. Chat Translation에는 월 9.99달러, 29.99달러, 99.99달러 플랜이 제시되어 있어 B2C 반복 과금의 가능성은 있다. 그러나 유료 사용자 수, 유지율, 해지율, 고객별 계약기간이 공개되지 않아 이 요금제가 안정적인 구독 매출로 자리 잡았는지는 아직 확인할 수 없다.

수주잔고는 보고서 기준일 현재 데이터 판매 26.65억원, 플랫폼 0.03억원, 솔루션 2.84억원으로 합계 29.52억원이다. 보고서 제출 이후 데이터 판매에서 총 65.35억원의 추가 계약을 체결했다고 공시하지만, 계약금액 전부가 단기간 매출과 이익으로 인식되는 것은 아니므로 계약의 납품시기·원가·갱신 여부를 함께 봐야 한다.

2. 연구개발과 데이터 구축 능력은 진입장벽이지만, 독점력과 동일하지 않다

보고서 기준 연구개발 인력은 70명으로 전사 인원의 약 35.0%이며, CTO·CDO·CSO 조직이 서버·앱·인프라 보안, 데이터 정제·증강 파이프라인, LLM 번역·이미지 인페인팅·음성인식 등을 담당한다. 공시상 번역 플랫폼과 데이터 제공 서비스에 특화된 특허도 17개 보유하고 있다. 말뭉치 구축 플랫폼, 이미지 인페인팅, LLM 기반 번역 검수, 실시간 통번역 솔루션까지 제품화된 연구 실적이 있다는 점은 단순 번역 중개업과 구분되는 부분이다.

다만 AI 데이터 시장은 고객이 필요한 데이터 유형과 품질 기준이 계속 바뀌고, 대형 모델 사업자와 데이터 공급자가 직접 거래할 수 있는 시장이다. 특허와 자체 파이프라인이 모든 데이터 유형에 대한 독점권을 보장하지는 않는다. 회사가 강조하는 의료·법률·과학·게임 분야의 전문 데이터와 영어-아랍어 같은 희소 언어 데이터가 실제로 일반 데이터보다 높은 단가와 재계약률을 만들어내는지가 핵심 검증 포인트다.

3. TTM 이익은 유지되지만 최근 분기 수익성은 후퇴했다

2025년 연간 매출은 359.80억원, 영업이익은 61.54억원이었다. 2025년 1분기와 2026년 1분기를 연결하면 TTM 매출은 약 365.85억원, 영업이익은 약 59.16억원, TTM 영업이익률은 16.17%다.

핵심 리스크: 데이터 수요는 커져도 공급자의 마진이 자동으로 커지지는 않는다

  1. 1.대형 고객 집중: 미국 소재 글로벌 빅테크 A사가 당기 매출의 10% 이상을 차지한다. 대형 고객의 데이터 구매 주기·검수 기준·가격 협상에 따라 분기 실적이 크게 변할 수 있다.
  2. 2.AI 데이터의 상품화: 일반 언어 데이터는 경쟁 공급자가 늘어날수록 가격이 낮아질 수 있다. 전문·희소 언어 데이터가 실제 매출과 재계약에서 차별화되는지 확인해야 한다.
  3. 3.최근 분기 적자: 매출은 전년 동기보다 늘었지만 2026년 1분기 영업이익률은 -1.23%였다. 연구개발과 데이터 구축 비용이 매출 확장보다 빨리 증가하면 TTM 이익도 약해질 수 있다.
  4. 4.계약금액과 매출 인식의 차이: 제출 이후 65.35억원의 추가 계약을 체결했지만 납품 시기와 원가가 공개되지 않았다. 계약 체결만으로 이익의 질을 판단하면 안 된다.
  5. 5.B2C 확장 검증 부족: Chat Translation의 요금제는 제시되어 있으나 유료 가입자·사용량·해지율이 공개되지 않았다. 솔루션 매출이 데이터 판매의 변동성을 실제로 낮추는지 봐야 한다.

다음 평가에서 확인할 지표는 대형 고객 매출 비중의 변화, 데이터 판매의 재계약률과 매출총이익, 솔루션 유료 계정·사용량, 연구개발비 증가 이후의 영업레버리지다.

총평

총평: 45점 — 좋은 데이터·AI 사업 기반은 있으나, 아직 ‘해자’보다 ‘성장 옵션’에 가깝다

플리토는 다국어 데이터 수집과 품질관리, 번역 플랫폼, AI 솔루션을 한 조직 안에서 연결하고 있다. 70명의 연구개발 인력, 17개 특허, 전문·희소 언어 데이터 전략은 경쟁자가 단기간에 그대로 복제하기 어렵다. TTM 영업이익률도 16% 수준으로, 적자 성장주로만 볼 회사는 아니다.

하지만 이 강점은 고객의 반복 구매와 높은 단가로 확인되어야 한다. 현재 매출의 큰 축이 데이터 판매이고, 대형 글로벌 고객 비중이 높으며, 2026년 1분기에는 영업적자로 돌아섰다. 사용자 네트워크가 커질수록 자동으로 경쟁력이 강화되는 사업도 아니어서, 데이터 품질과 신규 계약이 매 분기 비용을 넘어서는지를 계속 확인해야 한다.

점수가 올라갈 조건

  • 데이터 판매의 재계약률·고객 유지율과 전문 데이터의 단가가 공개될 것
  • 2026년 1분기 적자 이후 연구개발 투자를 유지하면서 영업이익률이 회복될 것
  • 특정 글로벌 고객 의존도가 낮아지고 복수의 장기 고객이 늘어날 것
  • Chat Translation·Live Translation이 반복 과금 매출로 자리 잡을 것

점수가 내려갈 조건

  • 대형 고객 계약의 단가 인하 또는 발주 공백이 반복될 것
  • 신규 솔루션 확대에도 데이터 구축비·지급수수료만 늘고 마진이 회복되지 않을 것
  • 수주 증가가 납품 지연·원가 상승으로 이어질 것

현재는 데이터 자산과 AI 연구 역량을 근거로 45점을 부여한다. 50점 이상으로 올라가려면 매출 성장보다 고객 유지와 현금이익의 반복성이 먼저 증명되어야 한다.
